## 🎟️ Dinkenesh Event Management System

**React · Vite · Node.js · Express · PostgreSQL · Prisma · Redis · JWT · Socket.IO**

A full-stack event management platform covering event discovery, organizer operations, ticketing, payments, check-in, moderation, analytics, and notifications.

### Highlights

* JWT authentication with role-based access control
* Event creation, discovery, filtering, and lifecycle management
* Organizer and staff management workflows
* Ticket purchasing with payment initialization and verification
* QR-based ticket scanning and duplicate-scan prevention
* Moderation reports, bans, and appeals
* Organizer approval and administrative workflows
* Analytics and CSV export endpoints
* Centralized notification and template-based email service
* Backend organized into controllers, routes, services, middleware, and utilities
* Frontend and backend test suites with unit and integration coverage

https://github.com/fasikaill/Dinkenesh-Event-Management-System

## 🎫 Event Management System

**Next.js · React · TypeScript · PostgreSQL · Prisma · Redis · WebSockets · Better Auth · Chapa · Zod**

A modular event platform designed around separate business domains for events, ticketing, reservations, payments, check-in, notifications, moderation, and external integrations.

### Highlights

* Modular domain-oriented application structure
* Event, ticket, reservation, and waitlist workflows
* Payment and refund lifecycle handling
* QR-based ticket issuance and check-in
* Real-time features through **WebSockets**
* Redis-backed application and delivery workflows
* Authentication with **Better Auth**
* Validation using **Zod** and forms built with React Hook Form
* Notification delivery pipeline with a dedicated worker process
* Webhook and external-provider integration models
* PostgreSQL persistence with Prisma ORM
* Dedicated scripts for database management, workers, WebSockets, testing, and validation

🔗 **Repository:**
https://github.com/fasikaill/Event_Management_System

## 🗂️ Centralized Crime Management System (CCMS)

**Next.js · React · TypeScript · Tailwind CSS · FastAPI · Python · PostgreSQL · SQLAlchemy · Redis · Docker**

A centralized case-management system built around structured workflows for cases, evidence, personnel, departments, court processes, reporting, and administration.

### Highlights

* Case creation, tracking, details, and bulk status management
* Evidence management and bulk export workflows
* Person and officer management
* Department and organizational workflows
* Court case and legal management features
* Reporting and administrative configuration
* Role and permission guards across the application
* Shared data tables, filters, forms, dialogs, and drawers
* FastAPI backend with modular application structure
* PostgreSQL persistence with SQLAlchemy and Alembic migrations
* Redis integration and Docker Compose environment
* Frontend testing with **Vitest** and end-to-end testing with **Playwright**
* Storybook component development and accessibility tooling

🔗 **Repository:**
https://github.com/fasikaill/Crime_managment_system
